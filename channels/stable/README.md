# nanoos — stable channel

Generic NanoOS packages intended for normal supported NanoOS installations.

This source directory is not a live Pacman repository. Signed binary packages and repository databases will be published by the release pipeline after package review, machine testing, hosting, and key management are configured.

Stable promotion requires a successful package build, source and checksum review, install/upgrade/removal checks on the supported real-machine test setup, and working signature verification. Packages with CPU-specific instructions must not enter this generic channel.
